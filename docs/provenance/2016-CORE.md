MaxSlopeAngle=89, Health_XML=100 and MaxHealth=100. These are explicit file values,
not assumptions about constructor defaults.

`audit-player` runs seven Bevy command updates with logged input, direction, raw
direction, fraction, outcomes and WalkTo state. World analog 0.25 produces unit
direction and fraction 0.25; diagonal normalization may produce fraction
0.99999994. Zero input preserves that prior fraction. Camera and detached branches
pass. Five added tests bring the suite to 23. The first normalization assertion
had an incorrect expected float (0.79999995 versus 0.8); corrected analytically,
without changing the normalization implementation.

This is command handling, not character locomotion, collision response, jumping,
animation or a playable client. Non-finite, overflowing and underflowed vectors
are diagnostic errors rather than claims about native acceptance. Full native
execution, i386 floating-point equivalence and behavioral parity are **not tested**.

`physics::audit` reads each Part's original frame, Velocity and RotVelocity, then
tests seven independent unconstrained bodies in Bevy. It does not infer joints or
classify the original rig as free-fall. One Bevy update runs one native free-fall
step; no wall-clock scheduling is inferred from this fixture. After 240 steps,
maximum Y position error versus the double analytic curve is 0.000218649 studs;
maximum Y velocity error is 0.000691672 studs/second. The explicit diagnostic
tolerance is 0.002 for each; this compares to mathematics, not native runtime.
The root ends near Y=-80.100235 with Y velocity=-196.20071.

Three added tests bring the suite to 26. They distinguish middle-velocity position
integration from semi-implicit Euler, verify native negative quaternion branches,
and distinguish the quaternion derivative from an exponential rotation step.
DynamicGravity's default flag/configuration remains unresolved and is not guessed.
Contact forces/impulses, classification, assemblies, anchored-body scheduling,
collisions, sleeping, Humanoid state forces/jumping and native differential
execution remain unimplemented / **not tested**. No supplied XML or binary changed.
